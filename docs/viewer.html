GitShelves viewer moved

The maintained Three.js viewer now lives in web/. Run cd web && npm ci && npm run dev, then open the shown local URL.

The new viewer preserves local STL loading, baseplate detection, _colorN and legacy levelN classification, color visibility, OrbitControls, and STLLoader without runtime CDN dependencies. Existing static-host links may redirect this page to the deployed root after release.

Read the migration and local setup guide.
